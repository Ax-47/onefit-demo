# OneFit — Web App Demo

เว็บแอปเดโม **OneFit**: กินของชอบได้ทุกเมนู ด้วย AI คำนวณแคลอรี พร้อมมินิเวิร์กเอาต์ชดเชยส่วนเกิน

เป็นเว็บแบบ static ไม่ต้อง build เปิด `index.html` ในเบราว์เซอร์ได้ทันที หรือเปิดผ่าน GitHub Pages
(Settings → Pages → Deploy from a branch → เลือกบรานช์นี้ / root) และติดตั้งลงหน้าจอมือถือเป็น PWA ได้

```
index.html            โครงหน้า + แท็บบาร์
css/app.css           ธีมสว่าง/มืด และคอมโพเนนต์
js/data.js            ฐานข้อมูลอาหาร 30 เมนู, ร้านพาร์ทเนอร์, ท่าออกกำลังกาย 25 ท่า, โปรแกรม, เหรียญรางวัล
js/app.js             ตรรกะของแอปทั้งหมด (state เก็บใน localStorage)
js/opengym-data.js    คลังท่าไม่ใช้อุปกรณ์ 325 ท่าจาก openGym (สร้างด้วย tools/import-opengym.mjs)
js/body-paths.js      รูปร่างกายสำหรับแผนภาพกล้ามเนื้อ
media/gif/            ภาพเคลื่อนไหวสาธิตท่า
manifest.webmanifest  ข้อมูล PWA
sw.js                 แคชออฟไลน์ (ลงทะเบียนเฉพาะบน github.io)
```

## ฟีเจอร์

**บันทึกอาหาร**
- สแกนรูปอาหารด้วย AI (จำลอง) แสดงเมนูที่ตรวจพบ ความมั่นใจ ส่วนผสมพร้อมแคลอรี โปรตีน/คาร์บ/ไขมัน และปรับปริมาณ 0.25–2 เท่า
- ค้นหาจากฐานข้อมูล 30 เมนู แยกหมวด สตรีทฟู้ด คาเฟ่ บุฟเฟต์ ฟาสต์ฟู้ด คลีน พร้อมรายการ "กินบ่อย"
- สแกน QR ร้านพาร์ทเนอร์ เพื่อดูแคลอรีทั้งเมนูของร้านและสิทธิพิเศษ
- กรอกเมนูเองได้ (ชื่อ แคลอรี และสารอาหาร)
- บอกว่าต้องออกกำลังกายกี่นาทีจึงจะเผาผลาญมื้อนั้นได้

**วันนี้**
- วงแหวนแคลอรีที่เหลือหรือเกินเป้า เป้าหมายโปรตีน/คาร์บ/ไขมัน ตัวนับน้ำดื่ม 8 แก้ว
- แยกมื้อเป็น เช้า กลางวัน ของว่าง เย็น
- ถ้ากินเกินเป้าจะมีแบนเนอร์ชวนทำเวิร์กเอาต์ชดเชย

**เวิร์กเอาต์**
- มินิเวิร์กเอาต์ชดเชย 10–15 นาที จัดให้อัตโนมัติจากแคลอรีส่วนเกิน โฟกัสเฉพาะจุดได้ (Premium)
- 6 โปรแกรม: HIIT, หน้าท้อง, ขาและก้น, แขนและอก, Office Break, ยืดเหยียด
- ความหนัก 3 ระดับ (30/30, 40/20, 45/15 วินาที) และปรับอัตโนมัติจากการให้คะแนนหลังจบเซสชัน
- คลังท่า 25 ท่า มีวิธีทำ ท่าง่ายลง/ถนอมเข่า และแคลอรีต่อนาที
- สร้างโปรแกรมเองได้ (Premium)
- ตัวจับเวลาเต็มจอ นับถอยหลังเตรียมตัว เสียงพากย์ภาษาไทย เสียงบี๊บ 3 วินาทีสุดท้าย ย้อนกลับ/ข้าม/พัก และกันจอดับ
- ทำเซสชันชดเชยครบจะได้คูปองจากร้านพาร์ทเนอร์

**จาก openGym**
- คลังท่าไม่ใช้อุปกรณ์ 325 ท่า ค้นหาและกรองตามส่วนของร่างกาย พร้อมภาพเคลื่อนไหวสาธิตและวิธีทำ
- ภาพเคลื่อนไหวในหน้ารายละเอียดท่าและระหว่างออกกำลังกาย
- แผนภาพกล้ามเนื้อด้านหน้า/หลัง แสดงกล้ามเนื้อที่ฝึกใน 7 วัน บอกส่วนที่ยังไม่ได้ฝึก และแสดงในหน้าโปรแกรม ตัวสร้างโปรแกรม และหน้าจบเซสชัน
- ลองทำท่าใดก็ได้ 3 รอบ หรือเพิ่มท่าจากคลังลงโปรแกรมของตัวเอง

**สถิติ**
- กราฟแคลอรีสุทธิ 7 วันเทียบเส้นเป้าหมาย และกราฟน้ำหนัก (แตะเพื่อดูตัวเลข)
- วันออกกำลังกายต่อเนื่อง ปฏิทิน 28 วัน ชาเลนจ์เพื่อน และเหรียญรางวัล 9 แบบ

**โปรไฟล์**
- ตั้งค่าเริ่มต้นเป็นขั้นตอน คำนวณ BMR/TDEE ด้วยสูตร Mifflin-St Jeor แล้วตั้งเป้าหมายแคลอรีและสารอาหาร
- แพ็กเกจ Free/Premium 89 ฿, โค้ดชวนเพื่อน, คูปอง, เปิด/ปิดเสียง, ธีมสว่าง/มืด

## หมายเหตุ
- การจดจำอาหารจากรูปเป็น **การจำลอง** (เลือกเมนูจากโทนสีของรูป และให้ผู้ใช้แก้ให้ถูกได้) ในแอปจริงต้องใช้โมเดล Computer Vision
- แคลอรีจากการออกกำลังกายคำนวณจาก MET × น้ำหนักตัว ซึ่งเป็นค่าประมาณ
- ไม่มีการชำระเงินจริง รายชื่อเพื่อนในชาเลนจ์เป็นข้อมูลตัวอย่าง และข้อมูลทั้งหมดอยู่ในเบราว์เซอร์ของผู้ใช้
