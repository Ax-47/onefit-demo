# OneFit — Web App Demo

เดโมเว็บแอป **OneFit**: กินของชอบได้ทุกเมนู ด้วย AI คำนวณแคลอรี พร้อมมินิเวิร์กเอาต์ชดเชยส่วนเกิน

เป็นไฟล์เดียว (`index.html`) ไม่ต้อง build — เปิดในเบราว์เซอร์ได้ทันที หรือเปิด GitHub Pages จาก branch นี้

## ฟีเจอร์ในเดโม (อิงจาก pitch deck)

| ฟีเจอร์ | ในเดโม |
|---|---|
| Universal AI Food Scanner | อัปโหลด/ถ่ายรูปอาหาร หรือเลือกเมนูตัวอย่าง 24 เมนู (สตรีทฟู้ด, คาเฟ่, บุฟเฟต์, ฟาสต์ฟู้ด, คลีน) → แสดงเมนูที่ตรวจพบ, ความมั่นใจ, ส่วนผสมพร้อมแคลอรี, โปรตีน/คาร์บ/ไขมัน, ปรับปริมาณ 0.5–2× |
| Calorie-Offset Workouts | ถ้ากินเกินเป้า แอปจัดมินิเวิร์กเอาต์ 10–15 นาที ไม่ใช้อุปกรณ์ (40 วิ ออกแรง / 20 วิ พัก) พร้อมตัวจับเวลา แคลอรีคำนวณจาก MET × น้ำหนัก |
| Freemium | Free: สแกน 5 มื้อ/วัน + เวิร์กเอาต์ทั้งตัว · Premium 89 ฿/เดือน: สแกนไม่จำกัด + เวิร์กเอาต์เฉพาะจุด (หน้าท้อง/ต้นขา/แขน) |
| B2B Partnership | ทำเวิร์กเอาต์ชดเชยครบ → ได้คูปองส่วนลดอาหารคลีนจากร้านพาร์ทเนอร์ |
| User Referral | โค้ดชวนเพื่อน รับ Premium ฟรี 1 เดือน |

## หมายเหตุ
- การจดจำอาหารจากรูปเป็น **การจำลอง** (เดาจากโทนสีของรูป + ให้ผู้ใช้เลือกเมนูที่ถูกต้อง) — ในแอปจริงจะแทนด้วยโมเดล Computer Vision
- ไม่มีการชำระเงินจริง ข้อมูลเก็บใน `localStorage` ของเบราว์เซอร์
